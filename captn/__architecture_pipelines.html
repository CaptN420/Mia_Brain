🧩 CaptN — Architecture : 3 Pipelines Indépendantes

autogen = génération de CODE · MirrorAgent = validation d'ÉQUATIONS · complètement séparés

⚠️ Pourquoi tu vois des équations dans les logs ?
Quand le dashboard démarre, il lance le Captn runtime qui initialise tous les composants — y compris MirrorAgent + MathValidator (pour la librairie Alchimie).
Ces logs Ndot = J * A viennent du MirrorAgent qui valide des transformations mathématiques. Ils n'ont rien à voir avec autogen qui ne touche qu'à du code Python.

💡 C'est ici que les logs Ndot = J * A apparaissent.
Le MirrorAgent reçoit des messages de type "mirror" et appelle MathValidator pour classifier. Rien à voir avec autogen — c'est un système de raisonnement mathématique symbolique pour la librairie Alchimie.
